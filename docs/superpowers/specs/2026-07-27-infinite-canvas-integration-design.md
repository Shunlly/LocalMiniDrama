# 无限画布混合主工作台设计

**日期：** 2026-07-27  
**状态：** 设计基线，待产品复核  
**适用范围：** LocalMiniDrama 桌面端 Web 工作台

## 1. 目标与边界

将参考站点的自由创作体验吸收到 LocalMiniDrama，而不是复制其源码或改变本项目的业务真源。升级后的 `/film/:id/canvas` 仍然是短剧生产工作台，同时增加一个与生产数据共享的自由创作层。

本次首个交付阶段的目标是：

- 保留现有剧本、角色、场景、道具、分镜、媒体和工作流节点及其生产门禁。
- 增加自由文本、图片、视频、生成配置和参考素材节点。
- 支持在同一项目内拖拽、缩放、框选、多选、连线、复制、粘贴、删除、撤销、重做和视口保存。
- 让自由节点可以引用现有项目素材，并把自由节点结果转为角色参考、场景参考、分镜参考或媒体入口。
- 吸收参考站点的桌面视觉层级：低干扰点阵背景、紧凑顶部状态栏、节点上下文操作条、底部创建工具条和选中节点侧栏。
- 真实外部 Provider、移动端触控、多人协作和完整画布助手接入继续遵循现有路线，不能为了视觉改造绕过现有安全门禁。

不复制参考项目的源代码、组件、图片、图标文件或本地存储实现。参考项目为 AGPL-3.0，本项目继续保持现有许可证与依赖边界；只实现可独立验证的交互理念和适合本项目的业务能力。

## 2. 用户与核心流程

### 2.1 制作流程模式

默认进入现有制作流程模式。用户看到剧本、素材、集数、分镜和媒体链，现有生成、工作流分组、状态轮询、保存状态和列表模式入口行为不变。新增模式切换只改变画布工作区呈现，不改变项目数据关系。

### 2.2 自由创作模式

用户切换到自由创作模式后：

1. 画布保留当前项目标题、保存状态、主题和返回入口。
2. 左侧素材栏可折叠，显示可引用的角色、场景、道具、分镜媒体和项目素材。
3. 底部工具条提供新建文本、图片、视频、生成配置、导入素材、撤销、重做、适配视图和背景切换。
4. 单击节点显示上下文操作条和右侧检查器；双击文本进入原位编辑；拖拽节点连接点可建立自由节点关系。
5. 生成配置节点读取上游文本和参考媒体，展示当前输入摘要、配置状态和生产就绪门禁。真实 Provider 未配置时必须显示明确的配置引导或 Mock 状态，不得伪装成已生成。
6. 选中自由节点后，用户可以将其保存为项目素材，或选择“转为生产参考”并指定角色、场景、分镜或媒体目标。转换前展示目标和覆盖范围，完成后保留原自由节点。
7. 刷新或重新进入画布后，自由节点、连线、节点位置、视口、背景模式和当前模式恢复。

### 2.3 关键体验原则

- 生产数据优先：自由节点永远是创作草稿或引用层，不直接覆盖角色、场景、分镜正文；只有显式转换动作才能回填。
- 状态可解释：保存中、保存失败、Provider 未配置、媒体不可用、转换失败都必须有可见原因和可重试动作。
- 不打断创作：面板采用停靠或浮层，不把用户强制带离画布；离开有未保存草稿时沿用现有保护机制。
- 键盘可用：焦点顺序、Escape 关闭浮层、Delete 删除选中、Ctrl/Cmd+A 全选、Ctrl/Cmd+C/V 复制粘贴、Ctrl/Cmd+Z 和 Ctrl/Cmd+Shift+Z 撤销重做。
- 桌面优先：首阶段验收视口为 1280x720、1366x768、1440x900，覆盖浅色与深色主题；移动端不作为本阶段完成条件。

## 3. 方案比较与选择

### 方案 A：完全替换现有生产画布

把现有业务节点改造成通用节点，所有剧本数据都通过自由节点表达。

优点是视觉和交互模型最接近参考站点；缺点是会破坏既有生产门禁、列表双视图、集数筛选、工作流组和数据兼容，迁移风险最大。本方案不采用。

### 方案 B：同一路由的混合主工作台（选择）

在现有 Vue Flow 画布上增加模式和自由节点层，业务节点继续由现有 adapter 生成，自由节点由独立 adapter 生成，最后合并渲染；两层通过明确的引用/转换动作连接。

优点是复用现有数据、API、测试和生产流程，能逐步交付并回退；缺点是需要处理两套节点生命周期、连接规则和历史记录。本方案能最大化用户价值并控制回归范围，作为实施基线。

### 方案 C：独立 `/canvas` 通用画布

另建一个与项目无关的通用画布，再通过导入导出或素材选择与短剧项目互通。

优点是隔离性高、实现自由；缺点是用户需要在两个工作台之间切换，项目上下文、权限、素材和生产状态容易分裂，不符合短剧连续创作流程。暂不采用，可作为未来无项目自由创作入口。

## 4. 前端架构

### 4.1 图模型边界

现有 `buildDramaCanvasGraph` 继续负责生产节点和业务连线，不把自由节点逻辑塞进业务 adapter。新增 `freeCanvasAdapter.js` 负责：

- 校验和规范化自由节点/连线。
- 把持久化模型转换为 Vue Flow 节点/边。
- 生成稳定的默认位置和节点尺寸。
- 计算自由节点引用的生产对象摘要。
- 从 Vue Flow 事件生成可持久化的最小变更。

视图层通过 `mergeCanvasGraphs(productionGraph, freeGraph, mode)` 合并图。制作流程模式默认渲染生产图；自由创作模式渲染生产上下文节点与自由图，生产节点可按筛选设置隐藏但不能从自由图删除。

### 4.2 组件职责

- `DramaCanvas.vue`：负责模式、加载、保存、路由保护、图合并和全局事件编排，不承载自由节点字段的细节。
- `FreeCanvasToolbar.vue`：负责创建节点、撤销重做、视图和背景动作，所有图标按钮必须有可访问名称和 tooltip。
- `FreeCanvasNode.vue` 或按节点类型拆分的节点组件：只负责展示与局部交互，不直接调用 API。
- `FreeCanvasInspector.vue`：编辑选中节点的标题、内容、引用、转换目标和错误重试动作。
- `CanvasHistory.js`：以可序列化快照记录自由图、视口和背景变化；生产工作流运行状态不进入自由图撤销栈。
- `freeCanvasAdapter.js` / `freeCanvasState.js`：负责模型规范化、上限校验、复制粘贴 ID 重写和边清理。

### 4.3 交互规则

- 自由节点允许连接；生产节点保持现有不可随意连接的约束，跨层连接只通过“引用/转为生产参考”动作建立语义关联。
- Delete/Backspace 删除自由节点和自由连线；删除节点同时清理其自由边，不删除项目生产实体。
- 复制粘贴生成新 ID，并重写粘贴子图内的边；引用的生产实体 ID保持不变。
- 拖入图片先进入现有上传/素材校验流程，成功后创建自由图片节点；失败时保留错误节点或明确错误提示，不写入不可信 URL。
- 节点生成中的状态必须可取消或重试，并且不能因刷新而伪造成功。
- 画布内容区域使用稳定的最小尺寸和 z-index 层级，节点、检查器、工具条和提示不互相遮挡。

## 5. 持久化与后端契约

### 5.1 兼容数据结构

继续保留现有 `metadata.canvas_layout`。在其旁边增加 `metadata.free_canvas`，避免覆盖旧版布局：

```json
{
  "free_canvas": {
    "version": 1,
    "mode": "production",
    "background": "dots",
    "viewport": { "x": 0, "y": 0, "zoom": 0.9 },
    "nodes": [
      {
        "id": "free:text:example",
        "type": "text",
        "title": "镜头想法",
        "position": { "x": 760, "y": 160 },
        "width": 280,
        "height": 180,
        "content": "",
        "status": "idle",
        "asset_ref": null,
        "storyboard_ref": null,
        "metadata": {}
      }
    ],
    "edges": []
  }
}
```

允许的自由节点类型为 `text`、`image`、`video`、`config`、`reference`。`content` 只保存可持久化的文本或本地媒体引用，不保存 API key、完整请求头或未经校验的巨大 base64。图片/视频优先使用现有上传服务返回的存储引用。

### 5.2 API 兼容

扩展现有 `PUT /api/v1/dramas/:id/canvas-layout`：

- 接受 `canvas_layout`、`free_canvas` 和 `workflow_groups` 的部分更新。
- 按项目 ID 校验归属并合并 metadata，不覆盖未知字段。
- 校验版本、节点类型、坐标、尺寸、边引用和数量上限；拒绝跨项目引用、循环巨型 payload 和非法媒体字段。
- 返回规范化后的保存结果和版本时间戳，前端使用响应确认保存成功。

节点上限首阶段为 500，自由边上限为 1000，单节点文本长度为 50,000 字符；上限触发时保留当前画布并给出可行动提示。

### 5.3 版本兼容

- 没有 `free_canvas` 的旧项目自动使用空自由层。
- `free_canvas.version` 不支持时只读生产画布，并提示升级，而不是丢弃未知数据。
- 导出 ZIP 保留 `free_canvas`；导入时再次运行同一套 schema 校验。
- 保存失败不清空本地内存状态；下次保存前合并最新服务端 metadata，避免覆盖其他字段。

## 6. 错误、网络与安全

- 所有保存、上传、转换和生成请求复用现有请求封装、超时、取消、重试和错误清理器。
- 外部图片 URL 只允许走已有媒体网络策略；自由节点不能绕过 SSRF、重定向敏感头清理和 MIME 校验。
- Provider 未配置时动作禁用原因必须写入按钮的可访问描述，并提供进入 AI 配置的明确入口。
- 任何错误消息只展示清理后的服务端信息，不泄露 API key、授权头、内部路径或原始上游响应。
- 自由节点数据按项目隔离；加载一个项目不得读取或写入另一个项目的节点和媒体。
- 导入/导出继续执行压缩包路径、媒体类型和资源大小校验。

## 7. 测试与验收

### 7.1 单元和契约测试

新增或扩展以下测试：

- `freeCanvasAdapter.test.js`：默认节点、规范化、未知类型拒绝、边清理、复制粘贴 ID 重写、旧数据兼容。
- `canvasHistory.test.js`：连续编辑合并、撤销/重做、视口和背景快照、历史上限。
- `canvasLayout`/后端路由测试：部分更新合并、项目隔离、数量/尺寸/字段上限和导入导出保留。
- 现有生产画布测试：节点 ID、工作流顺序、媒体失败状态、主题和无障碍契约无回归。

### 7.2 组件与浏览器验收

Playwright/E2E 至少覆盖：

1. 打开已有项目，切换制作流程/自由创作模式。
2. 新建文本和生成配置节点，编辑文本并建立连线。
3. 框选、多选、复制、粘贴、删除、撤销和重做。
4. 刷新后节点、连线、视口、背景和模式恢复。
5. 选择生产素材并创建自由参考节点，再将其转换到指定分镜参考入口。
6. 保存失败、上传失败、Provider 未配置和项目切换时的恢复提示。
7. 1280x720、1366x768、1440x900 的浅色/深色截图，检查工具条、节点、侧栏和检查器不重叠。

验收方分工：产品经理检查用户是否能理解下一步和结果归属；项目经理检查范围、回滚、数据兼容和证据绑定；开发完成后由测试与安全审计分别签字，Docker 和生产构建验证通过后才算本阶段完成。

## 8. 交付顺序

1. 先落 schema、adapter、历史状态和保存契约，补测试。
2. 再实现模式切换、自由节点、工具条、检查器和连接交互。
3. 接入素材引用与生产参考转换，补项目隔离和错误状态。
4. 完成视觉收敛、主题/可访问性和浏览器验收。
5. 最后跑全量前后端测试、Node 20 检查、依赖/源码安全审计、Docker 重建和发布证据。

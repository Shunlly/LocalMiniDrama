验收结论

本轮九项升级在桌面 Web 范围内有条件通过。项目入口、AI 配置、故事素材、制作页与画布已经形成一致的状态表达：用户能看到当前完成度、首个阻塞原因和唯一下一步；不可执行动作不再伪装成主按钮。

9 张证据

已知残余风险

以下两项不否定桌面功能验收，但必须保留在发布说明和后续计划中。

2 项保留
P1

主入口 chunk 偏大

生产构建成功，但主入口 JS 为 1,233.30 kB，gzip 后 401.83 kB，触发 Vite “chunk 大于 500 kB”警告。

影响集中在首次下载后的解析与执行成本，低性能设备和冷缓存环境更明显；当前没有功能阻断。

控制与退出条件
按路由和 Element Plus / Vue Flow 等依赖拆包，建立首屏 JS 预算，并用冷缓存性能数据确认改善。
P1

Host Node 24 与 better-sqlite3 限制

当前主机为 Node 24.11.0。后端语法检查通过，但本机依赖树不完整，原生模块 better-sqlite3 无可用加载路径，因此 Host 后端全量测试不能复现容器绿灯。

这是运行基线与原生 ABI 风险，不是本轮业务逻辑失败；Node 20 Docker 中 78/78 测试已通过。

控制与退出条件
继续以根目录 .nvmrc 和 Docker Node 20 为准；若要支持 Node 24，需单独完成干净安装、原生模块编译和全量回归。

延期边界

延期项不计入“九项桌面升级”完成率，也不能被当前的有条件通过结论覆盖。

不得扩张结论

移动 Web 完整重排

390px 首页、项目详情和制作页仍存在裁切或内部横向内容；完整画布仅提供“列表模式”逃生入口。移动端发布继续延期，直至头部动作、表单栅格、资源区和画布模式分别通过 390px / 768px 验收。

真实 AI 供应商端到端生成

本轮验证不消耗外部 API Key，不覆盖账号权限、额度、模型名、临时服务故障，也未实际完成图像、视频、TTS 与成片输出。连接测试本身不等同于真实生成验收。

专项可访问性与桌面壳跨平台

关键按钮、卡片与样式选择器已补键盘语义测试；但全流程 Tab 顺序、弹窗焦点圈定、屏幕阅读器、200% 缩放、颜色对比度数值，以及 Electron / macOS / Linux 安装包仍需独立矩阵处理。

发布建议

允许合入并发布本轮桌面 Web 九项升级；发布说明固定 Node 20 / Docker 基线，并明确移动端仍为延期范围。主 chunk 拆分和 Node 24 原生模块兼容进入后续工程任务，不阻塞当前桌面功能交付。

LocalMiniDrama 产品体验与发布验收

以实际桌面工作流为准，覆盖项目入口、AI 服务、本地素材、Wikimedia Commons 网络媒体、网页正文导入、剧集就绪度、制作台、画布和自由创作。移动端、代码签名、外部真实 Provider 深度联调、更多网络媒体平台与用途许可判断，以及通用模型自动发现按已确认范围后置。

按约后置

移动端与 touch 重排、Authenticode 签名、外部真实 Provider 深度联调、更多第三方图片/视频平台与用途许可判断，以及通用 `/v1/models` 自动模型发现。Wikimedia Commons 的搜索、作者与许可来源展示、预览和安全下载已实现；使用者仍需自行核对实际用途许可。未配置的视频与语音服务会在产品中明确阻断正式制作，并提供返回上下文完整的配置入口。

机器证据决定发布

最终干净源码提交之后生成的生产 E2E、Docker、Windows 制品、安全扫描和离线校验必须绑定同一提交，并由 GitHub checks 与可下载 artifacts 提供权威记录。

产品与项目联合验收

发现问题先回开发修复，再重新进入测试与审计

产品经理：桌面体验说明

  • 项目首页、紧凑就绪度、紧凑流水线、画布、素材中心和 AI 配置均有明确主任务与下一步；诊断详情不再抢占首屏。
  • 缺少视频或 TTS 能力时，正式命令失败关闭，同时保留可带上下文返回的配置入口。
  • 跨项目图片可以从素材中心挂载为分镜自由参考图或视频主参考图。
  • 素材选择器已阻止旧请求覆盖新请求，加载、错误、空态和确认操作保持一致。
  • 项目包导入失败改为持久页内反馈，提供安全文件名、可操作原因、重新选择和关闭入口。
  • 素材选择器空态可直接清除筛选或前往素材中心上传，并通过受限返回地址回到原制作台。
  • QA 报告与当前处理运行严格绑定；新运行尚无 QA 时不会回退显示或执行旧报告的自动修复。
  • 素材写入成功与列表刷新失败分开反馈；恢复动作只读刷新列表，并用请求代次阻止旧失败或旧成功覆盖更新结果。
  • AI 配置把“服务状态”和“配置管理”分开，左右方向键同步迁移选中态与焦点；服务直达链接落在正确工作区。
  • AI 可用状态同时校验默认配置、凭据、模型/工作流和最近连接结果；修复入口会展开并聚焦缺失字段，配置变更后旧测试结果立即失效。
  • 素材中心的“导入网页 URL”可选择已有项目并直接打开、聚焦 URL 输入；已完成过工作流的项目也无需先手动展开历史步骤。
  • 制作台在 769px 展开 180px 导航时把头部操作分行排列，保留全部命令且无控件重叠或横向滚动。
  • 2026-07-23 当前源码手工验收覆盖 AI 校验、网页导入、来源标识、画布、1024px 制作台和项目列表；这些结果仍只提供产品上下文，正式结论必须由最终同一提交的 machine artifacts 给出。

项目经理：发布判断由机器证据承担

  • 桌面范围、后置边界、发布失败条件和回滚责任由文档与自动化合同共同定义。
  • 源码、Docker、生产 E2E、回滚和安全证据必须由最终干净提交重新生成；历史结果不能迁移为当前结论。
  • GitHub CI 须将 Windows 制品、SBOM、秘密扫描和离线校验绑定同一远端提交；完成前不创建正式 Release。
  • QA 只能完成当前工作流明确持有的合成记录；幂等重试、Provider 证据、任务、剧集和最终媒体必须在同一事务与同一所有权下收敛。
  • 任何同一提交门禁失败都回到开发阶段，不允许用本页或人工说明替代通过记录。

本轮关键收口

用户体验

  • 移除“微信我”，减少无关入口。
  • 扩展 AI 厂商、协议和模型配置。
  • 自由创作与项目工作流按服务就绪度阻断。
  • 画布最低可读缩放、聚焦、返回上下文和列表模式收口。
  • 项目列表增加真实视觉封面、状态筛选、稳定统计层级和直达制作工作台的继续入口。
  • 画布分镜编辑增加未保存草稿指纹、关闭/列表/切换节点确认；批量导入等待父层异步保存完成。
  • 素材上传、解析和工作流启动期间保留浏览器离开保护，完成后自动解除。
  • AI 配置弹窗固定标题与 Tab，内容唯一滚动；测试操作具备 loading、禁用和可访问名称。
  • 项目就绪度与全流程生成默认紧凑，只保留分数、当前阻断和唯一下一步；运行中任务会自动展开完整控制。
  • AI 配置拆分“服务状态 / 配置管理”，服务直达与键盘左右导航都落在正确工作区。
  • 连接测试状态按非敏感运行实例隔离，删除陈旧配置记录；缺凭据、模型或工作流时始终优先给出具体修复动作。
  • 并发路由使用单调令牌保持最新加载遮罩，旧导航取消、重定向或报错不会提前恢复底层交互。
  • 网页 URL 导入意图贯穿项目选择、完成态工作流展开、输入框聚焦和安全返回上下文。
  • 旧 QA 不再串入新运行；素材创建成功后的刷新异常明确标记“已导入”，禁止重复提交并提供只读恢复。
  • 核心界面统一为中文生产术语。

安全与发布

  • Provider URL、endpoint、settings 和导出凭据脱敏。
  • ZIP 条目数在完整 materialize 前限制，覆盖 ZIP64。
  • AI 默认配置由唯一索引和写事务保证。
  • Release 构建禁止自动发布，制品复验后才创建草稿。
  • FFmpeg 使用固定可信摘要，备份默认排除 Provider 凭据。
  • 合成重试刷新当前 Provider 证据并检查实际更新行数；后处理替换的最终视频必须非空且重新通过 ffprobe。
  • CycloneDX 1.4/1.5/1.6 按各自规范严格校验组件类型与字段类型，拒绝数字 specVersion 和依赖根漂移。
  • 回滚检查点改为白名单配置脱敏归档，恢复前严格校验凭据排除声明，恢复后要求重新配置并测试。
  • Trivy 读取四份 SBOM 并扫描三份真实 Dockerfile；后端绑定目录启动降权例外有明确范围并于 2027-07-17 到期复审。

无障碍与证据边界

tracked 审查关注点

  • 项目卡片键盘入口、弹窗焦点和画布面板聚焦。
  • 模式控件、状态提示、错误提示和关键按钮的可访问名称。
  • 项目视觉封面失败时降级到带语义的占位，不显示破损图片图标；筛选无结果提供可恢复空态。
  • 桌面 viewport、横向溢出、成片与分镜视频的加载、解码和播放须由最终机器 E2E 重新证明。

证据限制

  • 截图不能单独证明完整屏幕阅读器兼容；结论结合自动化语义契约。
  • 真实云 Provider 的计费、限流和长耗时行为按范围后置。
  • 素材截图只提供本地上传/筛选、Wikimedia Commons 来源展示和网页正文导入的说明性上下文；更多第三方平台、具体用途许可兼容性和当前候选下载结果仍需单独验证。
  • AI 配置截图只证明预设厂商、自定义兼容厂商和手工模型，不证明通用 `/v1/models` 自动发现。
  • 恢复后不会携带密钥，管理员必须重新录入并执行连接测试。
  • GitHub CI 是推送后的远端独立复验；机器发布结论以同一源码提交的安全证据、manifest 和离线校验为准。

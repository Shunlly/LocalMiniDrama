# localminidrama-storyboard-draft

Purpose: create editable storyboard rows from episode scripts and continuity anchors.

Inputs:
- `drama_id`
- episode scripts
- character continuity snapshots

Outputs:
- storyboard drafts with image and video prompts

Rules:
- Include duration, action, image prompt, and video prompt for each storyboard.
- Respect current character identity anchors and stages.
- Missing real provider output is acceptable only as mock workflow planning.
